# (admin) — Super Admin (role=super_admin)

URL ขึ้นต้นด้วย `/admin/...` เสมอ (ตรงกับ `homeFor()` ใน `lib/auth.ts`)

| หน้า | โจทย์ข้อ | สถานะ |
|---|---|---|
| `admin/settings` แก้เกณฑ์จำแนก + อัตราค่าธรรมเนียม | US-09 | ใช้งานได้ |
| จัดการผู้ใช้/สิทธิ์ | M1 | ยังไม่เริ่ม |
| แก้รายการเอกสาร | US-09 | ยังไม่เริ่ม |
| แก้จุดติดต่อของ อปท. 19 แห่ง | US-09 | ยังไม่เริ่ม |

**หน้ากลุ่มนี้คือหลักฐานว่าระบบเป็น config-driven จริง — อย่าทิ้ง**

วิธีสาธิตที่เร็วที่สุด:
1. `/operator/wizard` กรอก 8 ห้อง 36 คน -> ได้ "ที่พักแรม ประเภทที่ 1"
2. `/admin/settings` แก้ผู้เข้าพักสูงสุดของ `RULE-NOT-HOTEL` จาก 30 เป็น 40
3. กดปุ่ม "ลองจำแนก" ในหน้าเดียวกัน หรือกลับไปหน้า wizard กรอกเดิม
   -> ได้ "ไม่เข้าข่ายโรงแรม" โดยไม่มีใครแตะโค้ดเลย
