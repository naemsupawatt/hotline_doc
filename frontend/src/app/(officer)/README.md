# (officer) — เจ้าหน้าที่ท้องถิ่น (role=officer)

URL ขึ้นต้นด้วย `/officer/...` เสมอ (ตรงกับ `homeFor()` ใน `lib/auth.ts`)

| หน้า | โจทย์ข้อ | สถานะ |
|---|---|---|
| `officer/queue` คิวคำขอในเขตของตน | M8 | ใช้งานได้ |
| `officer/applications/[no]` ตรวจเอกสาร + สรุปผล | M8 M9 | ใช้งานได้ |
| คลังกรณีศึกษา | S2 | ยังไม่เริ่ม |

**ทุกหน้าในกลุ่มนี้ต้องกรองด้วย อปท. ของผู้ใช้เสมอ — ดู T-09**
การกรองทำที่ฝั่งเซิร์ฟเวอร์ (`services/officer.py`) หน้าจอไม่ได้กรองเอง
คำขอนอกเขตจึงเปิดไม่ได้แม้จะพิมพ์ URL ตรง ๆ และความพยายามนั้นถูกบันทึกไว้
