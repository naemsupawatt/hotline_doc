# ภาพประกอบ HoTLinE Doc

สร้างใหม่ด้วย **built-in `image_gen`** โดยอ้างอิงทิศทางภาพโรงแรม ชุมชน และโทนมิ้นต์จากตัวอย่างของผู้ใช้ ภาพไม่มีข้อความฝังอยู่ เพื่อให้ข้อความภาษาไทยในเว็บไซต์อ่านได้และปรับตามขนาดหน้าจอ

| ไฟล์ | ขนาด | จุดที่ใช้ |
| --- | --- | --- |
| `hotel-garden.webp` | 1200 × 800 | หน้าต้อนรับ/สมัครสมาชิก และคำแนะนำในหน้าประเมินที่พัก |
| `coastal-community.webp` | 768 × 512, transparent | เมนูด้านข้างทุกบทบาท และหัวหน้าภาพรวมส่วนกลาง |
| `hotel-sketch.webp` | 768 × 512, transparent | หัวหน้าคำขอของผู้ประกอบการ และคิวคำขอของเจ้าหน้าที่ |

Prompt ฉบับเต็มของทั้งสามภาพอยู่ที่ [`docs/illustration-prompts.json`](../../../docs/illustration-prompts.json)

ไฟล์ WebP ลดขนาดจากภาพที่สร้าง พร้อมเก็บ alpha ของภาพพื้นโปร่งใส การแสดงผลใช้ `Illustration.tsx` ผ่าน Next Image พร้อมขนาดภาพและ `sizes` ตามพื้นที่ใช้งาน ภาพเป็นของตกแต่งจึงใช้ `alt=""` และไม่ใช้แทนสถานะหรือคำแนะนำที่สำคัญ
