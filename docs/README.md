# เอกสารส่งมอบ (Deliverables)

โจทย์กำหนดให้ส่ง 6 ชิ้น — มีเพียงชิ้นที่ 4 เท่านั้นที่ต้องใช้เครื่องคอมพิวเตอร์
ที่เหลือร่างบนกระดาษก่อนแล้วค่อยพิมพ์ลงไฟล์ได้ (โจทย์ระบุเองว่า wireframe
"จะเป็นภาพร่างหรือไฟล์ออกแบบก็ได้")

| # | สิ่งที่ต้องส่ง | ไฟล์ในโฟลเดอร์นี้ | สถานะ |
|---|---|---|---|
| 1 | เอกสารความต้องการ + User Stories + Use Case Diagram | `requirements.md` | ยังไม่เริ่ม |
| 2 | ER Diagram + SQL + คำอธิบาย Normalization | `database.md` | ยังไม่เริ่ม |
| 3 | Prototype / Wireframe อย่างน้อย 5 หน้า | `wireframes/` | ยังไม่เริ่ม |
| 4 | Working Software + Git repository | โค้ดใน repo นี้ | กำลังทำ |
| 5 | ผลการทดสอบอย่างน้อย 10 กรณี | `test-cases.md` | ยังไม่เริ่ม |
| 6 | สไลด์นำเสนอ 7 นาที + ถาม-ตอบ 3 นาที | `presentation/` | ยังไม่เริ่ม |
